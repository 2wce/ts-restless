---
title: 'React Query v4 migration'
description: Move existing Query v4 applications to the fork's Query v5 baseline.
---

The first stable ts-restless v4 release supports TanStack Query **v5**. Query v4 is removed from the current source baseline; there is no `/legacy` adapter. Existing published upstream v3 packages and fork prereleases are unchanged.

Follow the [Query v5 migration guide](/query-v5-migration) and the [React Query v5 documentation](/client/react-query-v5). Upgrade the native library before adopting the new adapter baseline.
